# Portfólio - Daniel

Site feito pra atividade avaliativa da disciplina. A regra era só HTML, sem
usar CSS em nada, então o site tá bem simples visualmente mesmo, o foco foi
na estrutura semântica.

## Páginas

- html/index.html -> página inicial
- html/sobre.html -> sobre mim, tem uma citação do professor e uso de details/summary
- html/projetos.html -> os projetos que já fiz, com tabela, progress, meter, video
- html/contato.html -> formulário de contato e um audio

## O que tem em cada requisito

- header, nav, main, section, aside, footer em todas as páginas
- tabela 3x3 com rowspan e colspan (em projetos.html)
- formulário com date, file, range, datalist, required e placeholder (em contato.html)
- details/summary em duas páginas (sobre.html e projetos.html)
- figure/figcaption em duas páginas (index.html e projetos.html)
- abbr, mark, del, ins, blockquote, cite, progress, meter espalhados pelo site
- audio e video local nas pastas audio/ e video/
- nada de style=, tag style, center, cellpadding ou align — só HTML puro mesmo

## Autoria

- tag time com a data da prova (24/09/2026), na página inicial
- blockquote com uma frase sobre HTML que o professor falou em aula, na página sobre mim
- comentário HTML na página inicial contando uma dificuldade que tive fazendo o site
